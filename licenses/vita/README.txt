Vita binary license files
=========================

These files are exact upstream license or notice texts for code included in,
statically linked into, or used to generate import/startup objects for the Vita
VPK. The component index and modification disclosures are in
THIRD_PARTY_NOTICES.txt at the repository root and at licenses/ inside the VPK.

The project GPL is ../LICENSE in the repository and GPL-3.0.txt in the VPK.
The h264bitstream LGPL is third_party/h264bitstream/LICENSE in the repository
and LGPL-2.1-h264bitstream.txt in the VPK. The Mononoki OFL is
assets/LICENSE-Mononoki.txt in the repository and OFL-Mononoki.txt in the VPK.
