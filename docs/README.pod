=head1 NAME

Vita Moonlight - Moonlight streaming client and Windows host companion for
PlayStation Vita

=head1 VERSION

0.14.7

=head1 DESCRIPTION

Vita Moonlight streams Sunshine or Apollo applications to a PlayStation Vita.
The recommended profile uses the Vita panel's native 960x544 resolution at
60 FPS, H.264 SDR, and an 8 Mbps bitrate. The Windows companion provisions and
controls a dedicated virtual display, configures controller support, and
restores the physical display after a stream.

=head1 USAGE

Install the VPK on the Vita. On Windows, run the packaged host installer and
open Vita Moonlight Host from the Start menu. Choose C<Set up or repair this
PC>, run C<Check readiness>, pair the Vita in Sunshine, and launch Steam Big
Picture, Desktop, or a configured game.

The Vita interface provides the same core stream and input settings before and
during a session. In-stream resolution or controller capability changes use
their corresponding controlled reconnect action.

=head1 DIAGNOSTICS

The top-right performance overlay can show frame rate, network information, or
advanced decoder and packet statistics. The dedicated real-time diagnostics
screen does not write a file. Optional support logging is off by default and
begins only when the user chooses C<Start support log>. It records concise
system, configuration, connection, decoder, motion-state, and periodic network
events rather than every touch, button, typed character, or gyro sample.

=head1 FILES

=over 4

=item F<ux0:data/moonlight/moonlight.conf>

Typical Vita configuration path. The application can select a documented
fallback storage location.

=item F<ux0:data/moonlight/moonlight.log>

Typical optional support-log path. The diagnostics screen shows the exact
active path.

=back
