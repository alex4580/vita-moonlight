Modification and build disclosures
----------------------------------

The release source contains every project modification. In particular:

* moonlight-common-c's pinned RTSP source receives the exact checked patch in
  patches/moonlight-common-c before compilation.
* Mbed TLS 3.6.7 is built from the locked official archive with the
  project-maintained GPL-3.0-or-later Vita socket, entropy, and platform patch
  in vendor/vita-source. Modified files are identified by that patch and by
  its inserted change notices.
* The Vita package build disables unnecessary position-independent output in
  zstd and makes libpng recognize the Vita Unix-like library naming convention.
* curl is configured for static Mbed TLS, zlib, and Zstandard support; FreeType,
  libjpeg-turbo, libvita2d, Expat, Opus, and bzip2 are statically built for Vita.
* The clean-room mDNS implementation in third_party/mdnsniff replaces the
  former ambiguously licensed submodule and is GPL-3.0-only project code.

Exact source identities, archive byte counts, SHA-256 values, SDK runtime
revisions, and any unresolved redistribution blocker are machine-readable in
tools/vita-corresponding-source.lock.json and the release source manifest.
